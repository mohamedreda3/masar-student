# مسار العربية — لوحة الطالب (Frontend · React)

نموذج تفاعلي **كامل وجاهز للربط بالباك إند** للوحة طالب منصة «مسار العربية» لتعليم العربية لغير الناطقين بها.
**41 شاشة** تعمل ببيانات وهمية موحّدة تمثّل عقد الـAPI حرفياً، ومحتوى وحدة حقيقية من فريق المنهج (الاحتياجات والرغبات · Grade 6 · Year 7 · Developing).

> **للمطورين — ابدؤوا من هنا:**
> 1. `docs/API-CONTRACT.md` — كل صادر في `src/data.js` ↔ endpoint مقترح بشكله الكامل.
> 2. `docs/ROUTES.md` — الـ41 شاشة، ملف كل واحدة، وما تحتاجه من البيانات.
> 3. `src/api/client.js` — هيكل عميل الـAPI الجاهز (دالة لكل endpoint) — اربطوا فيه وبدّلوا استيرادات `data.js` تدريجياً.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5199
npm run build    # إنتاج → dist/  (~118KB gzip JS، ~17KB gzip CSS)
npm run preview  # معاينة نسخة الإنتاج
```

باراميترات للعروض: `?theme=pink&mode=dark&fs=lg`
(الثيمات: `blue`(افتراضي)/`pink`/`purple`/`coral`/`gold`/`emerald`/`teal`/`sky`/`indigo`)

## التقنيات
- Vite 5 · React 18 · react-router-dom (HashRouter) — **بلا مكتبات UI** (CSS خام بتوكنز CSS variables، RTL، خط Tajawal).
- Web Audio للأصوات التفاعلية (بلا ملفات) + `<audio>` للمقاطع التعليمية.
- لا حالة عامة (state management) — كل شاشة تقرأ بياناتها؛ الحالة الشخصية عبر `localStorage` (3 مفاتيح) و`location.state` لتمرير نتيجة الكويز.

## التسلسل الهرمي الملزم (رسمة العميل — لا يُغيَّر)

```
وحدة (Unit) ← مثال: الاحتياجات والرغبات
 └─ مرحلة (Stage) / صف (Grade) ← نفس الوحدة بدروس مختلفة لكل صف
     └─ مستوى مساري (Group): مبتدئ → ناشئ → متطور → متقدم → متقن   [يراه المعلم فقط]
         └─ درس (Lesson)
             └─ 9 خطوات ثابتة: هيا نبدأ → المعجم اللغوي → الاستماع → القراءة → التحدث
                → الكتابة → أنشطة التحدي → تذكرة الخروج → اختبار قصير (10 درجات)
                (زر «أحتاج مساعدة» داخل كل مهارة — الدعم ليس خطوة مستقلة)
```

## قواعد عمل غير قابلة للتفاوض (قرارات العميل الموثقة)
1. **الطالب لا يرى سلّم المستويات الخمسة** — يرى «مجموعته» فقط (`levels` للمعلم). الترقية بقرار المعلم.
2. **الوحدات تُفتح بتكليف المعلم** لا بتسلسل مقفل (`stations[].status`).
3. **نوعا تقييم**: الاختبار القصير (كل درس، 10 درجات، ميكس محركات) + الختامي (المهارات الأربع، ~5/سنة؛ التحدث والكتابة بتصحيح معلم — **لا تصحيح آلي لهما**).
4. **لا شارات/نقاط/كونفيتي داخل شاشات التمرين** — والمكافآت **مشروطة بالنتيجة** (شارة ≥90، احتفال ≥60).
5. نواتج التعلم بصيغة «أستطيع أن…» عربي+إنكليزي على مستوى النشاط والوحدة والتقرير، مربوطة بأكواد المعايير الرسمية `LO.AR.x.x.x`.
6. ملاحظات المعلم دائماً: **نقاط القوة + الخطوة التالية**.
7. كل نص: عربي أساسي + إنكليزي صغير تحته (`.e`/`.en`)؛ النصوص التعليمية الطويلة تحمل `data-tr` للترجمة عند التمرير (`.tr-hover`). **لا مبدّل لغة**.
8. الصوت التعليمي دائماً بسرعات 0.75x/1x/1.25x (`playClip(src, rate)`).
9. القائمة العلوية **8 عناصر بالضبط** (`nav` في data.js).
10. كل صور البطاقات بنسبة **16:9** موحّدة (`aspect-ratio` في styles.css).

## التكيف (Adaptive) — v1 بالقواعد، جاهز للنقل للباك إند
- `pages/Result.jsx → adaptivePlan(pct)`: <60 دعم · 60–89 متابعة · ≥90 تحدي + شارة.
- `pages/Home.jsx → MySkills`: «مقترح لك اليوم» = أضعف مهارة.
- `QuizRun.jsx` يمرّر النتيجة الحية عبر `navigate('/result', { state: { pct } })` — الباك إند يعيد `pct` + `plan` من `POST …/quiz/attempts`.

## محركات الأسئلة
23 محركاً تفاعلياً في `pages/Engines.jsx` بثمانية تصنيفات — وهي **المواصفة البصرية لمحرر الأنشطة في لوحة المعلم**. الاختبار القصير يستخدم 5 أنواع منها فعلياً (`type: mcq | listen | order | input` + `engine` للعرض). مولّد الاختبارات (`pages/TestBuilder.jsx`) يبيّن شكل بنك الأسئلة الموسوم المطلوب.

## الجودة
- WCAG: `:focus-visible`، `prefers-reduced-motion` يوقف كل الحركة (بما فيها الشرارات)، تباين مدروس بالداكن مع كل الثيمات.
- استجابة كاملة 320px → 1680px (مدقَّقة على 375/550/768/1024)؛ بلوك `!important` في آخر `styles.css` مقصود لتجاوز `gridTemplateColumns` المكتوبة inline.
- صور الشبكات `loading="lazy" decoding="async"`، والبناء الإنتاجي بلا مكتبات خارجية.
